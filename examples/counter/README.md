# Лічильник 0–1 на ESP-IDF

Мініпроєкт для ESP32-S3-N16R8 та індикатора BLS-1106BS зі спільним анодом.
Після запуску показує `0`, потім щосекунди перемикається: `0 → 1 → 0 → …`.
Клас `SevenSegment`, параметри `static constexpr`, superloop з `esp_timer_get_time()`.
Без Arduino та динамічної пам’яті.

| Сегмент | GPIO | Контакт індикатора |
|---|---|---|
| A | 4 | 7 |
| B | 5 | 6 |
| C | 6 | 4 |
| D | 7 | 2 |
| E | 15 | 1 |
| F | 16 | 9 |
| G | 17 | 10 |

COM (контакти 3, 8) — до 3.3 V. Кожен сегмент — через резистор ~330 Ω.
Сегменти вмикаються рівнем LOW; DP (контакт 5) не підключений.
Окремі LED на GPIO8/9/10 (червоний/жовтий/зелений, active HIGH)
ініціалізуються вимкненими.

З кореня репозиторію:

```sh
get_idf
cd examples/counter
idf.py build
idf.py -p /dev/cu.usbmodem2101 flash monitor
```

Порт у команді потрібно замінити, якщо після підключення плати він змінився.
Інтервал і GPIO задаються в `main/config.hpp`. PSRAM для цього завдання не потрібна.
