# Три незалежні світлодіоди без блокування

Підключив три LED до ESP32-S3: кожен GPIO → резистор 220 Ом → довга
ніжка LED (анод), коротка ніжка (катод) → спільний GND плати.

| LED | GPIO | Інтервал перемикання |
|---|---|---|
| LED1 | GPIO4 | 200 мс |
| LED2 | GPIO5 | 500 мс |
| LED3 | GPIO6 | 1000 мс |

Один `esp_timer` викликає спільний `loop()` кожні 10 мс. Усередині час
зчитується через `esp_timer_get_time() / 1000`, а кожен LED має власну
часову позначку. Немає `delay()`, sleep або циклів очікування.
Пропущені інтервали враховуються без накопичення зсуву фази.
Повний цикл світіння вдвічі довший за інтервал перемикання.

Збірка ESP-IDF v6.1, C++17, flash 16 МБ; PSRAM не використовується.
Тести часової логіки пройшли. Прошито плату, у UART підтверджено
перемикання та зчитані рівні GPIO (`MATCH`). Після виправлення з'єднання
з GND усі три LED працюють — перевірено на бредборді.

Збірка з каталогу проєкту:

```sh
zsh -ic 'get_idf && idf.py build'
```

Перед прошиванням знайти поточний порт пристрою `1A86:55D3`, серійний номер
`5CBC388025`, і підставити його замість наведеного:

```sh
/Users/dlytvyne/.espressif/tools/python/v6.1/venv/bin/python -m serial.tools.list_ports -v
zsh -ic 'get_idf && idf.py -p /dev/cu.usbmodem5CBC3880251 flash'
zsh -ic 'get_idf && idf.py -p /dev/cu.usbmodem5CBC3880251 monitor'
```

Консоль UART — 115200 бод; вихід із monitor — `Ctrl+]`. На старті є два
рядки `CHECK` із лічильниками та рівнями GPIO, далі програма працює тихо.
